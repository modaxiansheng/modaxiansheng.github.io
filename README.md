# Ziying Song — Academic Homepage

Personal academic homepage for Ziying Song, built with static HTML and CSS.

## Edit

Update `index.html` for content, `styles.css` for appearance, and `assets/` for images. No build step or dependencies are required.

## Preview

From this directory, run `python -m http.server 8000` and open http://localhost:8000/, or use any static web server.

## GitHub Pages

In the repository's **Settings → Pages**, select **Deploy from a branch**, choose **master** and **/ (root)**, and save. Keep `.nojekyll` in the repository root.

Site URL after deployment: https://modaxiansheng.github.io/
